# 蒸馏依据与来源边界

本 Skill 于 2026-10-14 根据用户明确要求及《写稿服务详解》可访问片段整理。

## 用户本次明确确认的约束

Rubric 不漏点；每点最小逻辑闭环；Part 化成文；评分点之间贯通；Junior/Senior 缩放；严格字数/时间；预算与 Excel 一致；预算说明含 how spent、top two costs、attractiveness、competitiveness、constraints、two savings；Brand Value 含 two values、engagement、sales vs experience、identity、market image；三项结论简短回扣；避免无效细节与重复；支持最小改动压缩。

## 可访问历史片段支持的偏好

接口仅返回最近五轮，没有更早轮次游标，也没有原始 rubric 或 Excel 附件。因此不能声称已经读过“所有历史材料”或“完整评分表”。历史 assistant 的汇总不是原始 rubric，不能独立确认评分点或分值。

用户反复要求减短、至少减少 30、且不损失得分点；同时否定了改写过多的版本。这支持精确核对减少量、保护原结构和表达、避免整篇重写。

用户提供的英文片段展示了 timed flavor drops、tasting、Flavor Passport 与商业转化，以及 visible making、ingredient map、freshness clock 与长期品牌理解之间的机制。案例指标都是 three-day targets，不是已取得成绩。

片段的一个样稿含 Beijing、100 m²，后续 assistant 版本使用 Shanghai、96 m²，缺少可独立核实的更早更正材料。Skill 因此保留“跟随当前权威事实、核对依赖”的规则，不把其中任一版本设成默认。

## 不应从示例泛化的内容

YEAH GELATO、Two-Hour Flavor Market、场地、面积、三天、两小时、指标和口播词汇均属案例。Two values 的例子是商业价值与长期品牌价值，但未来 rubric 指定的定义优先。历史预算单位纠正只在 assistant 汇总可见；单位核查本身也由本次用户要求预算绝对一致所支持，不声称已核实历史具体行公式。

完整覆盖合同来自本次用户确认，不来自对缺失附件的猜测。后续获得原始 rubric、Excel 或更多 sample 后，应按材料修订相关要求与例子，不能假装当前文件已经包含它们。公开包不包含原始聊天导出、个人路径或实际比赛 workbook。
